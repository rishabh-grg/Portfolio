## How HTML and CSS Work Together

HTML is used to create the **structure** of the webpage.

For example:

```html
<h1>Rishabh Garg</h1>
```

CSS is used to change how the HTML element looks.

For example:

```css
h1 {
    color: white;
    text-align: center;
}
```

Therefore, HTML provides the structure while CSS provides the design.
